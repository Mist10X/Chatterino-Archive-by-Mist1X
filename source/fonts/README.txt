Montserrat SemiBold is a static wght=600 instance of the official Google Fonts Montserrat variable font:
https://github.com/google/fonts/blob/main/ofl/montserrat/Montserrat%5Bwght%5D.ttf
Family names were changed to Archive Montserrat for app-local isolation, consistently with the bundled Regular and Bold fonts.
