# Архив Chatterino by Mist1X

Локальный архив сообщений, модерации и повторов чата для Windows 10/11 x64.
Автор проекта — **Mist1X**. Это отдельное приложение; сам Chatterino в комплект не входит.

## Скачать и запустить

1. Открой [Releases](https://github.com/Mist10X/Chatterino-Archive-by-Mist1X/releases/latest).
2. Скачай **ChatterinoArchive-Setup-0.22.1-x64.exe** и пройди установку. Программа устанавливается для текущего пользователя, права администратора не нужны.
3. Открой архив через меню «Пуск» или ярлык, если выбрал его создание.
4. При первом запуске выбери отдельную папку для своих данных, вне папки программы `app`.
5. Подключи свой Twitch и добавь нужные каналы, пользователей и записи повторов.

Для переносной установки доступен **ChatterinoArchive-Windows-x64.zip**: распакуй его полностью в постоянную папку и запусти `app\ChatterinoArchive-by-Mist1X.exe`. «Code → Download ZIP» скачивает исходники, а не готовую программу.

Установщик хранит удаление программы отдельно от `app`, поэтому встроенные обновления его не затрагивают. Удаление программы не удаляет выбранную папку записей и файл выбора профиля. Перед ручной переустановкой закрой архив через значок возле часов → «Выйти из архива».

Программа пока **не подписана сертификатом издателя**. Windows SmartScreen может показать «Система Windows защитила ваш компьютер» из-за отсутствия репутации файла. Установщик не отключает защиту и не добавляет исключения. Проверяй источник скачивания и SHA-256 в `SHA256SUMS.txt`; подпись в будущем потребует отдельного сертификата или сервиса. Даже действительная подпись не гарантирует отсутствие предупреждения у нового выпуска. [Объяснение Microsoft](https://learn.microsoft.com/en-us/windows/apps/package-and-deploy/smartscreen-reputation).

В чистой установке нет чужих записей, выбранных пользователей, каналов для повторов и сохранённых входов. Исторические сообщения не появляются задним числом: приложение записывает доступные события во время своей работы. Повторы записываются только во время эфиров выбранных каналов.

## Подключение к Chatterino+

Прямое чтение Twitch работает отдельно. Для событий плагина нужен Chatterino с поддержкой Lua-плагинов. В качестве папки данных выбери его профиль, содержащий `Settings`. Помести файлы из `app\plugin` в `Plugins\history-tools` этого профиля, сохраняя существующую папку `data`, и включи плагин в настройках Chatterino. Перезапуск Chatterino при необходимости выполняется пользователем.

Для существующего архива можно запустить EXE с параметром `--profile "путь к профилю"`. Существующие настройки сохраняются. Общие баны Chatterino+ требуют отдельного подключения соответствующего сервиса и показывают только доступные ему сведения.

## Обновления

Приложение проверяет опубликованные стабильные выпуски этого репозитория. При появлении новой версии будет плашка «Обновление». Ручная проверка: **Оформление → Обновления** или **О программе → Проверить обновления**.

По кнопке «Скачать и установить» архив загружает пакет, проверяет контрольную сумму и состав файлов, завершает запись и перезапускает только себя. Данные хранятся отдельно. Если новая версия не подтверждает запуск, возвращается предыдущая. Одна резервная ZIP-копия программы сохраняется в папке данных, временные копии удаляются автоматически. Не размещай личные файлы внутри `app`.

Для выпуска обновлений автор меняет версию и отправляет тег вида `v0.22.1`. GitHub Actions проверяет и собирает приложение, создаёт **черновик** выпуска. Автор открывает его в Releases, проверяет описание и нажимает **Publish release**. Только после публикации пользователи увидят обновление. Исходники могут обновляться без публикации новой версии.

## Данные и исходники

Сообщения, настройки, изображения и входы находятся в выбранной папке данных. Пароли Twitch не собираются; вход выполняется на странице Twitch, токены защищены Windows DPAPI. Публичный Twitch Client ID в исходниках не является секретом. Чужие приложения не получают удалённый доступ к вашему архиву.

`source` содержит исходники интерфейса и фоновых служб, `plugin` — исходники нашего Lua-плагина. Исходный код самого Chatterino не входит в этот репозиторий. Инструкции сборки: [source/BUILD.md](source/BUILD.md). Лицензия проекта — MIT; сторонние компоненты перечислены в `licenses`.

## Кто выдал наказание и награды за баллы

В настройках Twitch можно включить получение имён модераторов и снова подтвердить вход. Запрашиваются только разрешения чтения. EventSub подключается к выбранным каналам, где аккаунт является модератором или владельцем. Имена исполнителей показываются в подробностях события и полной карточке. Для событий, полученных до подключения, имена автоматически не восстанавливаются.

Кнопка «Награды: мут и анмут» позволяет выбрать полученную награду, указать бота и точный текст его подтверждения с `{buyer}` вместо покупателя и `{target}` вместо фактического получателя. Правила задаются отдельно для канала и награды. Для каналов, где запрещённая цель приводит к муту покупателя, предусмотрен соответствующий переключатель.

Подпись покупателя появляется только при единственном подходящем сочетании покупки, подтверждения бота и фактического события. Окно исполнения — до двух минут после покупки; подтверждение должно быть в пределах пяти секунд от действия. Неоднозначные случаи остаются без подписи. Покупка может содержать ник (с @ или без него) и дополнительный текст; неоднозначные цели не сопоставляются автоматически. Отмена покупки исключает её из сопоставления. Статус выполнения награды сам по себе не доказывает, кто получил наказание.

Обычное IRC-подключение сохраняет доступные сообщения с меткой награды; полнота их доставки не гарантируется. Полный поток покупок через EventSub доступен только для собственного канала. Если бот не сообщает покупателя и фактическую цель, автоматическая подтверждённая привязка с таким форматом недоступна. Истечение мута и появление нового сообщения не считаются подтверждением купленного анмута.

## Интерфейс и аватары

В «Модерации» можно выбрать несколько типов событий или снять все галочки. Поиск каналов поддерживает Tab/Shift+Tab для перебора совпадений и Enter для подтверждения. В узком окне используется плотная компоновка.

Аватары и отображаемые имена получаются из официального Twitch Get Users API через собственное подключение Twitch. Сохранённые миниатюры доступны без сети. Обновление профилей проверяется в фоне, а поиск продолжает использовать логины без учёта регистра. Картинка в старой записи — текущий известный аватар, не исторический снимок профиля.
